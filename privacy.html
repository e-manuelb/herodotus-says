Privacy Policy

Last updated: November 10, 2026

Herodotus Says Uploader is a private tool operated by the owner of the Herodotus Says YouTube channel. It is not offered to the public.

What it accesses

With the channel owner's permission, the tool uses the YouTube Data API to upload videos, thumbnails and video details to the owner's own channel. It requests only the youtube.upload scope.

What it stores

The OAuth token is stored only on the owner's own computer. The tool does not collect, sell or share any personal data, and it does not access other users' accounts.

Revoking access

Access can be revoked at any time at myaccount.google.com/permissions.
